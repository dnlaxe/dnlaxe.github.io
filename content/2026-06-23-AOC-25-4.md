## Example input

```
..@@.@@@@.
@@@.@.@.@@
@@@@@.@.@@
@.@@@@..@.
@@.@@@@.@@
.@@@@@@@.@
.@.@.@.@@@
@.@@@.@@@@
.@@@@@@@@.
@.@.@@@.@.
```

## Solution

The solution starts by setting up a few constants and types. rounds controls how many rounds of removals to run. maxRolls is the minimum number of surrounding rolls needed for a roll to stay in place.

A Position stores one location in the grid. The Grid type is a map where each position represents a roll. If a position exists in the map, there is a roll there.

```
const (
	rounds   = 1
	maxRolls = 4
)

type Position struct {
	X, Y int
}

type Grid map[Position]struct{}
```

The parser reads the input file one line at a time. Each character is checked to see whether it is an @.

When the parser finds an @, it stores that position in the grid. Dots are ignored because they are empty spaces.

```
func parseDataIntoMap(filename string) (grid Grid, err error) {

	grid = make(map[Position]struct{})

	file, _ := os.Open(filename)
	defer file.Close()

	scanner := bufio.NewScanner(file)

	row := 0

	for scanner.Scan() {
		line := scanner.Text()

		for idx, pos := range line {
			if pos == '@' {
				grid[Position{X: row, Y: idx}] = struct{}{}
			}
		}
		row++
	}

	if err := scanner.Err(); err != nil {
		return Grid{}, fmt.Errorf("Scanning error")
	}

	return grid, nil
}
```

The main logic is in removableRolls. It goes through the grid and checks which rolls should be removed.

At the start of each round, it copies the current grid into updatedGrid. This makes sure all rolls are checked against the same starting grid for that round.

For each roll, the function counts how many rolls are around it. If there are fewer than maxRolls, that roll is removed from updatedGrid. The total number of removed rolls is also counted.

After the round finishes, the old grid is replaced with the updated one. If rounds is set to -1, the loop keeps running until a round removes no rolls.

```
func removableRolls(grid Grid) (count int) {
	count = 0
	updatedGrid := make(Grid, len(grid))

	for round := 1; rounds == -1 || round <= rounds; round++ {

		for pos := range grid {
			updatedGrid[pos] = struct{}{}
		}

		removedRolls := 0

		for pos := range grid {
			if surroundingRolls(pos, grid) < maxRolls {
				removeRoll(pos, updatedGrid)
				count++
				removedRolls++
			}
		}
		grid = updatedGrid
		if rounds == -1 && removedRolls == 0 {
			break
		}
	}

	fmt.Println(count)
	return count
}
```

The surroundingRolls function checks the eight positions around one roll. These are the spaces above, below, left, right, and the four diagonals.

For each surrounding position, the function checks whether that position exists in the grid. If it does, the number of surrounding rolls goes up by one.

The removeRoll function removes one position from the grid by deleting it from the map.

```
func surroundingRolls(pos Position, grid Grid) (rolls int) {
	surroundingPos := []Position{
		{X: pos.X - 1, Y: pos.Y - 1}, {X: pos.X - 1, Y: pos.Y}, {X: pos.X - 1, Y: pos.Y + 1},
		{X: pos.X, Y: pos.Y - 1}, {X: pos.X, Y: pos.Y + 1},
		{X: pos.X + 1, Y: pos.Y - 1}, {X: pos.X + 1, Y: pos.Y}, {X: pos.X + 1, Y: pos.Y + 1},
	}
	rolls = 0
	for _, pos := range surroundingPos {
		if _, exists := grid[pos]; exists {
			rolls++
		}
	}
	return rolls
}

func removeRoll(pos Position, grid Grid) (updated Grid) {
	delete(grid, pos)
	return grid
}
```

The main function reads the input file into a grid. Then it runs the removal calculation.

```
func main() {
	grid, _ := parseDataIntoMap("input.txt")
	removableRolls(grid)
}
```
