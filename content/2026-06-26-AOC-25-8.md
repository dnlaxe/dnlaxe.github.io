## Solution

The solution starts by setting up a few constants and types. Each box has an X, Y, and Z position. The Distance type stores the distance between two boxes, along with the indexes of those boxes in the input.

The Circuits type is used to keep track of connected groups of boxes. The unions slice stores each box’s current leader, and the sizes slice stores how large each circuit is.

```
const (
	connections     = 10
	largestCircuits = 3
)

type Position struct {
	X, Y, Z int
}

type Distance struct {
	distance         int
	PosIdx1, PosIdx2 int
}

type Circuits struct {
	unions []int
	sizes  []int
}
```

The parser reads the input file one line at a time. Each line contains three comma-separated numbers, so the parser splits the line, converts each part into a number, and stores them as a Position.

```
func parseData(filename string) (positions []Position, err error) {
	file, _ := os.Open(filename)
	defer file.Close()

	scanner := bufio.NewScanner(file)

	for scanner.Scan() {
		line := scanner.Text()

		parts := strings.Split(line, ",")

		x, _ := strconv.Atoi(parts[0])
		y, _ := strconv.Atoi(parts[1])
		z, _ := strconv.Atoi(parts[2])

		position := Position{
			X: x,
			Y: y,
			Z: z,
		}

		positions = append(positions, position)

	}
	if err := scanner.Err(); err != nil {
		return nil, err
	}

	return positions, nil
}
```

The createConnections function controls the main flow of the solution. It first finds every possible distance between boxes and sorts those distances from shortest to longest.

For part 1, it creates circuits using only the closest connections, then multiplies the sizes of the three largest circuits. For part 2, it keeps connecting boxes until everything is in one circuit, then uses the final connection that completed the circuit.

```
func createConnections(positions []Position, part int) {
	distances := findDistances(positions)
	sortDistances(distances)

	switch part {
	case 1:
		circuits, _ := createCircuits(distances, len(positions), part)
		multiplyLargestCircuits(circuits)
	case 2:
		_, finalPairs := createCircuits(distances, len(positions), part)
		box1 := positions[finalPairs.PosIdx1]
		box2 := positions[finalPairs.PosIdx2]
		fmt.Println(box1.X * box2.X)
	}
}
```

The createCircuits function uses a union-find structure to connect boxes together. At the start, every box is its own circuit, so each box is its own leader and each circuit has a size of 1.

The function then works through the sorted distances. If two boxes already have the same leader, they are already connected, so that distance can be skipped. Otherwise, the smaller circuit is merged into the larger one.

For part 1, the function stops after the required number of closest connections. For part 2, it stops once all boxes have been merged into a single circuit and returns the final connection used.

```
func createCircuits(distances []Distance, length int, part int) (Circuits, Distance) {
	unions := make([]int, length)
	sizes := make([]int, length)
	for i := range unions {
		unions[i] = i
		sizes[i] = 1
	}

	circuitCount := length

	for i := 0; i < len(distances); i++ {

		if part == 1 && i >= connections {
			break
		}

		leader1 := findLeader(distances[i].PosIdx1, unions)
		leader2 := findLeader(distances[i].PosIdx2, unions)

		if leader1 == leader2 {
			continue
		}

		if sizes[leader1] < sizes[leader2] {
			leader1, leader2 = leader2, leader1
		}

		sizes[leader1] += sizes[leader2]
		sizes[leader2] = 0
		unions[leader2] = leader1
		circuitCount--

		if part == 2 && circuitCount == 1 {
			return Circuits{
				unions: unions,
				sizes:  sizes,
			}, distances[i]
		}
	}

	return Circuits{
		unions: unions,
		sizes:  sizes,
	}, Distance{}
}
```

The distance helper functions build the full list of possible connections. Every box is compared with every box that appears after it in the input, so each pair is only checked once.

After the distances are created, they are sorted from shortest to longest. The distance itself is calculated using the 3D distance formula.

```
func findDistances(positions []Position) (distances []Distance) {

	n := len(positions)
	exactSize := (n * (n - 1)) / 2

	distances = make([]Distance, 0, exactSize)

	for index, position := range positions {
		for i := index + 1; i < len(positions); i++ {
			distance := Distance{
				distance: calculateDistance(position, positions[i]),
				PosIdx1:  index,
				PosIdx2:  i,
			}
			distances = append(distances, distance)
		}
	}
	return distances
}

func sortDistances(distances []Distance) []Distance {
	slices.SortFunc(distances, func(a, b Distance) int {
		return a.distance - b.distance
	})
	return distances
}

func calculateDistance(a Position, b Position) int {

	dx := float64(a.X - b.X)
	dy := float64(a.Y - b.Y)
	dz := float64(a.Z - b.Z)

	return int(math.Sqrt(dx*dx + dy*dy + dz*dz))
}
```

For part 1, the answer comes from the sizes of the largest circuits. This function collects the sizes of all circuit leaders, sorts them from largest to smallest, and multiplies the three biggest sizes together.

```
func findLeader(box int, unions []int) int {

	if unions[box] == box {
		return box
	}

	unions[box] = findLeader(unions[box], unions)
	return unions[box]
}
```

```
func multiplyLargestCircuits(circuits Circuits) (answer int) {

	var leaders []int
	for idx, val := range circuits.unions {
		if idx == val {
			leaders = append(leaders, circuits.sizes[idx])
		}
	}

	slices.SortFunc(leaders, func(a, b int) int {
		return b - a
	})

	answer = 1
	for i := 0; i < largestCircuits; i++ {
		answer *= leaders[i]
	}
	fmt.Println(answer)

	return answer
}
```

The main function reads the puzzle part from the command line, parses the input file, and then runs the connection logic for the selected part.

```
func main() {

	part := flag.Int("part", 1, "puzzle part: 1 or 2")
	flag.Parse()

	data, _ := parseData("input.txt")
	createConnections(data, *part)
}
```
