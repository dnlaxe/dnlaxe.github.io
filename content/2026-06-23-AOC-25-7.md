
## Solution

The solution starts by setting up a few types. Beam stores the current beam positions. If a number exists in the map, there is a beam at that column.

Splitters stores the splitter positions for each row. Each inner slice contains the column numbers where splitters appear on that row.

Timelines stores how many beams exist at each position. This is useful when the same position can represent more than one possible beam path.

```
type Beam (map[int]struct{})
type Splitters [][]int
type Timelines (map[int]int)
```

The parser reads the input file one line at a time. It starts by creating the initial beam map and setting startFound to false.

The startFound value is used to tell whether the starting point has already been found. Before the start is found, the parser looks for S. After the start is found, it starts collecting splitter positions marked with ^.

Empty rows made only of dots are skipped because they do not affect the beam.

```
func parseIntoInitialData(filename string) (initialBeam Beam, splitters Splitters, err error) {

	initialBeam = make(map[int]struct{})
	startFound := false

	file, _ := os.Open(filename)
	defer file.Close()

	scanner := bufio.NewScanner(file)

	for scanner.Scan() {
		line := scanner.Bytes()

		emptyLine := bytes.Repeat([]byte{'.'}, len(line))
		if bytes.Equal(line, emptyLine) {
			continue
		}

		var splitter []int

		for index, b := range line {

			if b == '^' && startFound == true {
				splitter = append(splitter, index)
			}

			if b == 'S' && startFound == false {
				initialBeam[index] = struct{}{}
				startFound = true
			}
		}

		if len(splitter) > 0 {
			splitters = append(splitters, splitter)
		}
	}

	if err := scanner.Err(); err != nil {
		return nil, nil, fmt.Errorf("Scanning error")
	}

	return initialBeam, splitters, nil
}
```

The countSplits function follows the beam through each row of splitters.

For each splitter, it checks whether the beam currently exists at that same position. If it does, the beam hits the splitter.

When a beam hits a splitter, the split count goes up by one. The original beam position is removed, and two new beam positions are added: one to the left and one to the right.

```
func countSplits(beam Beam, splitters Splitters) (splitCount int) {

	splitCount = 0

	for _, row := range splitters {
		for _, splitter := range row {
			if _, exists := beam[splitter]; exists {
				splitCount++
				delete(beam, splitter)
				beam[splitter+1] = struct{}{}
				beam[splitter-1] = struct{}{}
			}
		}
	}

	fmt.Println(splitCount)

	return splitCount
}
```

The countTimelines function is similar, but it counts all possible beam paths instead of only tracking whether a beam exists at a position.

Each position in timeLines stores a number. That number is how many timelines currently have a beam at that position.

When a beam hits a splitter, its timeline count is copied to the two new positions. The original position is then removed because the beam has split and moved away from that splitter.

```
func countTimelines(timeLines Timelines, splitters Splitters) (timelineCount int) {

	timelineCount = 0

	for _, row := range splitters {
		for _, splitter := range row {
			if _, exists := timeLines[splitter]; exists {

				timeLines[splitter+1] += timeLines[splitter]
				timeLines[splitter-1] += timeLines[splitter]

				delete(timeLines, splitter)
			}
		}
	}

	for _, beamCount := range timeLines {
		timelineCount += beamCount
	}

	fmt.Println(timelineCount)
	return timelineCount
}
```

The main function reads the input file and gets the starting beam and splitter rows.

It then creates the timeline map. Every starting beam position begins with one timeline.

Finally, it runs both calculations: one to count how many splitters are hit, and one to count how many timelines exist at the end.

```
func main() {
	initialBeam, splitters, _ := parseIntoInitialData("input.txt")

	timeLines := make(map[int]int)
	for i := range initialBeam {
		timeLines[i] = 1
	}

	countSplits(initialBeam, splitters)
	countTimelines(timeLines, splitters)
}
```
