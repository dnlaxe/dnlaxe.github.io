## Solution

Instead of checking every number in each interval, I generate only the numbers that could possibly be invalid.

An invalid ID has a very specific shape: it is made by repeating some prefix. For example, 123123 is created by repeating 123 twice. So for each interval, I look at the possible digit lengths and repeat counts, then generate candidate repeated numbers directly. After generating a candidate, I only need to check whether it falls inside the interval.

This avoids brute-forcing the full range. Large intervals may contain millions or billions of numbers, but the number of repeated-pattern candidates is much smaller.

Useful structs:

```
type Interval struct {
	start, end int
}

type PrefixPosition int

const (
	lowerBound PrefixPosition = iota
	upperBound
)
```

To parse data from text file:

```
func parseIntervals(s string) []Interval {
	chunks := strings.Split(s, ",")

	out := make([]Interval, 0, len(chunks))

	for _, p := range chunks {
		nums := strings.Split(p, "-")

		intStart, _ := strconv.Atoi(nums[0])
		intEnd, _ := strconv.Atoi(nums[1])

		out = append(out, Interval{
			start: intStart, end: intEnd,
		})
	}

	return out
}
```

To ensure IDs aren't counted twice because of overlapping ranges:

```
func mergeIntervals(r []Interval) []Interval {

	sort.Slice(r, func(i, j int) bool {
		return r[i].start < r[j].start
	})

	out := []Interval{r[0]}

	for i := 1; i < len(r); i++ {
		next := r[i]
		lastIdx := len(out) - 1
		last := out[lastIdx]

		if last.end >= next.start {

			if next.start < last.start {
				out[lastIdx].start = next.start
			}

			if next.end > last.end {
				out[lastIdx].end = next.end
			}

		} else {
			out = append(out, next)
		}
	}

	return out
}
```

For each interval, I first find the digit lengths covered by its start and end. For each possible total digit length, I get the prime repeat counts that could form a repeated number. For each repeat count, I extract a lower and upper prefix from the interval bounds, then generate candidate numbers by repeating each prefix. If the generated number has the expected digit length, falls inside the interval, and has not already been counted, I add it to the invalid ID list.

```
func findInvalidIDs(interval Interval) (invalidIDs []int) {

	startLen := digitLength(interval.start)
	endLen := digitLength(interval.end)

	for digitLength := startLen; digitLength <= endLen; digitLength++ {

		seen := make(map[int]struct{})

		for _, chunk := range getPrimeFactors(digitLength) {

			prefixStart := extractPrefix(interval.start, lowerBound, chunk)
			prefixEnd := extractPrefix(interval.end, upperBound, chunk)

			for i := prefixStart; i <= prefixEnd; i++ {

				if !hasRepeatedDigitLength(i, chunk, digitLength) {
					continue
				}

				number := repeatNumber(i, chunk)

				if interval.contains(number) {
					if _, exists := seen[number]; !exists {
						invalidIDs = append(invalidIDs, number)
						seen[number] = struct{}{}
					}
				}

			}
		}
	}

	return invalidIDs
}
```

I only check prime repeat counts. If an ID is made from a chunk repeated a composite number of times, then that ID can also be viewed as a larger chunk repeated by one of the composite number’s prime factors. For example, 123123123123 is 123 repeated 4 times, but it is also 123123 repeated 2 times. So composite repeat counts do not need to be checked separately.
To find prime factors of a number:

```
func getPrimeFactors(num int) (primeFactors []int) {

	if num%2 == 0 {
		primeFactors = append(primeFactors, 2)
		for num%2 == 0 {
			num /= 2
		}
	}

	for i := 3; i*i <= num; i += 2 {
		if num%i == 0 {
			primeFactors = append(primeFactors, i)
			for num%i == 0 {
				num /= i
			}
		}
	}

	if num > 1 {
		primeFactors = append(primeFactors, num)
	}

	return primeFactors
}
```

To create valid numbers with repeating chunks.

```
func repeatNumber(n, times int) int {
	result := n

	for i := 1; i < times; i++ {
		mult := 1
		tmp := n

		for tmp > 0 {
			mult *= 10
			tmp /= 10
		}

		result = result*mult + n
	}

	return result
}
```

To take starting chunk out of a number:

```
func extractPrefix(num int, pos PrefixPosition, chunks int) int {

	stringNum := strconv.Itoa(num)

	prefixLen := len(stringNum) / chunks

	if pos == upperBound && len(stringNum)%chunks != 0 {
		prefixLen++
	}

	p, _ := strconv.Atoi(stringNum[:prefixLen])
	return p
}
```

Helpers to make code more readable:

```
func digitLength(num int) int {
	return len(strconv.Itoa(num))
}

func hasRepeatedDigitLength(prefix, times, totalLength int) bool {
	return digitLength(prefix)*times == totalLength
}

func (r Interval) contains(n int) bool {
	return n >= r.start && n <= r.end
}
```

Main function:

```
func main() {
	dataBytes, err := os.ReadFile("input.txt")
	if err != nil {
		log.Fatal(err)
	}

	intervals := parseIntervals(string(dataBytes))

	intervals = mergeIntervals(intervals)

	for _, r := range intervals {
		fmt.Printf("Start num: %d, end num: %d\n", r.start, r.end)
	}

	totalSum := 0
	for _, interval := range intervals {

		invalidIDs := findInvalidIDs(interval)

		for _, id := range invalidIDs {
			totalSum += id
		}
	}

	fmt.Printf("Total sum: %v", totalSum)
}
```
