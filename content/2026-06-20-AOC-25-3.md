## Example input

```
987654321111111
811111111111119
234234234234278
818181911112111
```

## Solution

The solution starts by setting up a few constants and a Row type. Each row stores its digits as numbers, which makes the later calculation easier to work with.

```
const (
	filename = "input.txt"
	joltageLength = 2
)

type Row struct {
	digits []int
}
```

The parser reads the input file one line at a time. For each line, it converts every character into a digit and stores those digits in a Row.

```
func parseData(filename string) (allRows []Row, err error) {
	file, _ := os.Open(filename)
	defer file.Close()

    scanner := bufio.NewScanner(file)
    for scanner.Scan() {
    	line := scanner.Text()
    	row := Row{
    		digits: make([]int, 0, len(line)),
    	}
    	for _, char := range line {
    		row.digits = append(row.digits, int(char-'0'))
    	}
    	allRows = append(allRows, row)
    }
    if err := scanner.Err(); err != nil {
    	return nil, fmt.Errorf("Scanning error")
    }
    return allRows, nil

}
```

The main logic is in maxJoltage. It looks through a row and chooses the biggest possible two-digit number while keeping the digits in their original order.

The slots slice stores the digits chosen so far. When the function finds a better digit for an earlier slot, it replaces that digit and clears the later slots so they can be filled again correctly.

After choosing the best digits, the function turns them back into a normal number. For example, digits 9 and 8 become 98.

```
func maxJoltage(row Row, joltageLength int) (joltage int) {

    slots := make([]int, joltageLength)
    numbersLeft := len(row.digits)

    for _, digit := range row.digits {
    	numbersLeft--
    	replaced := false

    	for idx, slot := range slots {

    		if replaced {
    			slots[idx] = 0
    		}

    		if digit > slot && numbersLeft >= joltageLength-idx-1 && !replaced {
    			slots[idx] = digit
    			replaced = true
    		}
    	}
    }

    joltage = 0
    for _, slot := range slots {
    	joltage = (joltage * 10) + slot
    }
    return joltage
}
```

The total is calculated by finding the best joltage for each row and adding those values together.

```
func calculateTotal(rows []Row) int {
	sum := 0
	for _, row := range rows {
		sum += maxJoltage(row, joltageLength)
	}
	return sum
}
```

The main function reads the input and runs the calculation.

```
func main() {
	data, _ := parseData(filename)
	calculateTotal(data)
}
```
